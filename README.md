# CNTIR 查询机器人

一个在 AstrBot 里查询 CNTIR（欧洲卡车模拟 2 联机平台）信息的插件：查玩家、看位置、看服务器、看活动和新闻。

数据来自 [CNTIR 官网](https://cntir.ltchedui.com/developers)的公开数据，本插件只负责展示。

## 怎么用

**直接发中文指令就行，不用加前缀。**

| 我想做什么 | 这样发 |
|---|---|
| 绑定我的账号 | `绑定 1024`（ID 在官网个人主页查看） |
| 解绑、换主账号、看绑定 | `解绑` / `解绑 2` / `解绑 全部` / `切换 2` / `我的` |
| 查某个玩家（不发 ID 就是查自己） | `查询` / `查询 1024` / `查询 @群友` |
| 看他现在跑到哪了 | `定位` / `定位 @群友` |
| 看路上车多不多 | `路况` |
| 看服务器状态、平台数据、最近的在线情况 | `服务器` |
| 找车队、看车队资料 | `车队` / `车队 华夏` / `车队 12` |
| 看有什么活动、看某场活动详情 | `活动` / `活动详情 2`（数字是活动列表里的序号，不填就是第 1 场） |
| 看新闻、读新闻全文 | `新闻` / `新闻详情 1`（不填编号就是最新一篇） |
| 看公告、版本、帮助 | `公告` / `版本` / `菜单` |

几点说明：

- 一个群友最多绑定 3 个账号，第一个是主账号，平时查询默认用主账号。
- `定位`、`路况`、`服务器` 会发图片，其他指令都会以文字显示（不会被转成图片）。
- `服务器` 发的是深蓝色底板图片：顶部是平台统计，下面每个服务器一张卡（在线状态、人数、特性、近期流量波形、24 小时在线曲线、在线率/最长连续在线/上下线切换）。图片生成失败时会自动改发同样内容的文字版，不需要额外指令。
- `菜单` 也能说成 `帮助`、`help`、`说明`。
- 看到的资料最多有半分钟左右的延迟，这是为了避免给 CNTIR 服务器增加负担。

## 安装

把插件文件夹放进 AstrBot 的 `data/plugins/` 目录（或在 AstrBot 插件市场里搜索安装），重启 AstrBot 后发送「菜单」即可验证。
