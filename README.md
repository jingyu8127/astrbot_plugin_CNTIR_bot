# astrbot_plugin_CNTIR_bot

AstrBot 的 **CNTIR（欧洲卡车模拟 2 联机平台）** 查询插件。

> 数据来源：[CNTIR 公开数据 API](https://cntir.ltchedui.com/developers)（只读、免鉴权、免费）。
> 数据与图片版权归 CNTIR 平台所有，本插件仅为数据展示工具。

## 功能

| 指令 | 说明 |
|---|---|
| `绑定 <账号ID>` | 绑定 IR 账号（可绑多个，账号 ID 见官网个人主页） |
| `解绑 [序号/账号ID/全部]` | 解除指定绑定（默认解绑主账号） |
| `切换 <序号/账号ID>` | 切换主账号 |
| `我的` | 查看我的全部绑定（标注主账号） |
| `查询 [ID/@群友]` | 玩家资料：身份/车队/Steam/封禁/累计运单/最近运单（附头像） |
| `定位 [ID/@群友]` | 实时位置：服务器/速度/朝向/附近玩家 + ETS2 底图出图 |
| `路况 [服务器编号]` | 在线玩家分布：行驶统计/最快玩家/热点区域 + 全图出图 |
| `服务器` | 服务器状态：人数/排队/峰值/游戏内时间/特性开关 |
| `历史 [服务器] [小时]` | 在线历史曲线（在线率/最长在线/切换次数）+ SVG 状态图 |
| `统计` | 平台统计：在线/注册/运单/里程 |
| `车队 [ID\|关键词]` | 车队列表、搜索、详情 |
| `活动 [今日/精选/结束/页码]` | 活动列表 |
| `活动详情 <ID>` | 活动详情：规则/路线/DLC/报名玩家/参与车队 |
| `新闻 [页码]` | 新闻列表 |
| `新闻详情 <ID>` | 新闻正文（Markdown，超长截断并附原文链接） |
| `公告` | 当前生效的全站公告 |
| `版本` | IR 插件/启动器/支持的游戏版本 |
| `菜单` | 帮助菜单 |

**指令默认不需要 `任何` 前缀**：直接发「查询」「服务器」「路况」即可。
菜单额外支持 `菜单` / `帮助` / `help` / `说明` 四个写法。


「查询 / 定位」支持 `@群友` 代查对方绑定的主账号。

## 安装

1. 将本目录放入 AstrBot 的 `data/plugins/` 下（或通过插件市场安装）；
2. 依赖仅 `aiohttp`（`pip install -r requirements.txt`，AstrBot 会自动安装）；
3. 重启 AstrBot，发送 `cnt菜单` 验证。
